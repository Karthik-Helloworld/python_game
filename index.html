Product

Decide what “good” means.

  • A fixed data model with a flexible layer per customer
  • Pass rate as a release signal, with intent scored apart from SQL
  • Benchmarks that choose a model, across 189 AP and 477 AR queries
  • Multi-tenant design so the second client is not a rewrite
  • Test oracles and observability standards that outlive one feature
  • A public writing practice on AI, finance, and the career between them

  1. Query the warehouse.

    The agent should compile to SQL a reviewer can read. Metadata is the contract between the model and Snowflake.

  2. Score intent separately.

    A correct query can still answer the wrong business question. SQL correctness and business intent are different critics.

  3. Keep the frame fixed.

    The canonical model stays stable. Customer differences live in the transform and the prompt layer.
